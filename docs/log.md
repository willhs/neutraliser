## [2026-10-15] update | Every file records what was done to it (NEUTRALISER_* tags) and the skip check trusts it
The `.neutraliser` sidecar lives in whichever root a run started from, so a moved file, or a run started from a different root, lost its record and could be re-encoded again. The normalise pass now writes a `Stamp` as `NEUTRALISER_*` tags in the same ffmpeg command: version, profile, mode (linear/dynamic), gain, source codec/bitrate, measured I/TP/LRA, date. They go on the normalised audio stream and the container, after the existing per-stream `-map_metadata` mappings. With `--allow-dynamic` the mode is predicted from loudnorm's own linear rule (af_loudnorm.c). If loudnorm's summary disagrees, the output is remuxed once with corrected tags before commit.
